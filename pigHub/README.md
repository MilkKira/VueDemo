# PigHub Vue 学习复刻

这是对 [pighub.top](https://pighub.top/) 的 Vue 3 学习型复刻，包含精选图库、全部图库、搜索排序、下载和上传预览等主要界面与交互。

## 启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

完整实现说明见 [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md)。

> 本项目仅用于前端技术学习。图片通过原站公开 URL 展示，上传功能为纯前端演示，不会向原站提交数据。
